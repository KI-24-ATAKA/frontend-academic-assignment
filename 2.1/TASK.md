# Задача 2.1. Расчёт заказа

## Что вы создаёте

Небольшую программу, которая получает объект заказа, рассчитывает стоимость и возвращает итоговый объект.

Программа запускается через Node.js. HTML и браузерный интерфейс в этой работе не нужны.

## Что уже готово

В starter находятся:

- примеры заказов в `src/data.js`;
- код запуска в `src/index.js`;
- открытые проверки в `tests/order.test.js`;
- заготовки функций в `src/order.js`.

Изменяйте только:

```text
src/order.js
```

## Правила расчёта

Поля `price` и `quantity` приходят строками. Перед вычислениями преобразуйте их в числа.

Промокоды:

- `STUDENT10` — скидка 10%;
- `SALE20` — скидка 20%;
- любой другой код или отсутствие кода — скидка 0%.

Доставка:

- `pickup` — бесплатно;
- `courier` — 300 рублей;
- курьерская доставка бесплатна, если сумма **после скидки** не меньше 3000 рублей;
- неизвестный тип доставки должен вернуть `null`.

## Что сделать

Реализуйте функции по порядку:

1. `calculateSubtotal(price, quantity)` — стоимость товаров без скидки.
2. `calculateDiscount(subtotal, promoCode)` — сумма скидки в рублях.
3. `calculateDelivery(amountAfterDiscount, deliveryType)` — стоимость доставки.
4. `calculateOrder(order)` — полный расчёт заказа.
5. `formatOrder(orderResult)` — человекочитаемый текст заказа.

`calculateOrder()` должен возвращать новый объект вида:

```js
{
  product: "Практический JavaScript",
  quantity: 3,
  subtotal: 4500,
  discount: 450,
  delivery: 0,
  total: 4050
}
```

Если тип доставки неизвестен, `calculateOrder()` возвращает `null`.

`formatOrder()` должен вернуть многострочный текст. Денежные значения форматируйте через уже подготовленную функцию `formatMoney()`.

## Запуск

```bash
npm test
npm start
```

Сначала добейтесь прохождения тестов, затем посмотрите итоговый вывод программы.

## Самопроверка

- `price` и `quantity` преобразуются явно, а не складываются как строки;
- функции возвращают значения;
- неизвестный промокод не создаёт скидку;
- бесплатная доставка определяется по сумме после скидки;
- исходный объект заказа не изменяется;
- `calculateOrder()` собирает результат из ранее написанных функций;
- в коде нет значений, привязанных только к одному примеру заказа.
