# Задача 2.3. Корзина без неожиданных мутаций

## Что вы создаёте

Набор функций для изменения корзины.

Каждая операция получает текущее состояние и возвращает следующее состояние. Исходный объект корзины и его массив `items` изменять нельзя.

Программа запускается через Node.js. В модуле 3 такие же функции будут вызываться событиями интерфейса.

## Что уже готово

В starter находятся:

- начальная корзина и товары в `src/data.js`;
- последовательность операций в `src/index.js`;
- открытые проверки в `tests/cart.test.js`;
- заготовки функций в `src/cart.js`.

Изменяйте только:

```text
src/cart.js
```

## Модель корзины

```js
{
  items: [
    {
      productId: 1,
      title: "JavaScript: основы языка",
      price: 1800,
      quantity: 1
    }
  ],
  promoCode: null
}
```

Товар, передаваемый в `addItem()`, имеет форму:

```js
{
  id: 2,
  title: "CSS Grid на практике",
  price: 1600
}
```

## Что сделать

### 1. Добавление товара

```js
addItem(cart, product)
```

- если товара нет, добавить новую позицию с `quantity: 1`;
- если товар уже есть, увеличить его количество на 1;
- вернуть новый объект корзины и новый массив `items`.

### 2. Изменение количества

```js
changeQuantity(cart, productId, quantity)
```

- установить новое количество найденной позиции;
- если количество меньше или равно нулю, удалить позицию;
- `productId` и `quantity` могут прийти строками.

### 3. Удаление позиции

```js
removeItem(cart, productId)
```

Вернуть новую корзину без указанной позиции.

### 4. Промокод

```js
applyPromoCode(cart, promoCode)
```

- поддержать `STUDENT10` и `SALE20`;
- игнорировать регистр и пробелы по краям;
- пустой или неизвестный код сохраняется как `null`;
- вернуть новый объект корзины.

### 5. Вычисляемое резюме

```js
getCartSummary(cart)
```

Вернуть:

```js
{
  linesCount: 2,
  itemsCount: 3,
  subtotal: 5000,
  discount: 500,
  total: 4500
}
```

`linesCount` — число позиций, `itemsCount` — сумма `quantity`.

Резюме вычисляется из корзины. Не добавляйте `subtotal`, `discount` и `total` внутрь состояния корзины.

## Главное ограничение

После операции исходное состояние должно остаться прежним:

```js
const nextCart = changeQuantity(cart, 1, 3);

console.log(nextCart !== cart);             // true
console.log(nextCart.items !== cart.items); // true
console.log(cart.items[0].quantity);        // старое значение
console.log(nextCart.items[0].quantity);    // новое значение
```

Spread создаёт только поверхностную копию. Если меняется объект позиции внутри массива, его тоже нужно заменить новым объектом.

## Запуск

```bash
npm test
npm start
```

## Самопроверка

- нет `push`, `splice` и прямых присваиваний в свойства входной корзины;
- новая позиция добавляется через новый массив;
- существующая позиция обновляется через новый объект;
- удаление использует выборку элементов;
- исходная корзина не меняется после цепочки операций;
- summary всегда можно пересчитать из `items` и `promoCode`;
- функции не используют глобальную корзину из `data.js`.
