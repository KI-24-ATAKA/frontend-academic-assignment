# Задача 2.2. Каталог данных

## Что вы создаёте

Набор функций для обработки каталога учебных материалов.

Функции должны находить, фильтровать, искать, сортировать и анализировать массив объектов. Интерфейс пока не нужен: программа запускается через Node.js.

## Что уже готово

В starter находятся:

- каталог из 12 элементов в `src/products.js`;
- пример общего сценария в `src/index.js`;
- открытые проверки в `tests/catalog.test.js`;
- заготовки функций в `src/catalog.js`.

Изменяйте только:

```text
src/catalog.js
```

## Модель товара

```js
{
  id: 1,
  title: "JavaScript: основы языка",
  category: "books",
  price: 1800,
  rating: 4.8,
  inStock: true,
  tags: ["javascript", "frontend", "beginner"]
}
```

## Что сделать

### 1. Поиск по идентификатору

```js
findProductById(products, productId)
```

Функция возвращает один товар или `undefined`. `productId` может быть числом или строкой.

### 2. Фильтрация

```js
filterProducts(products, filters)
```

Поддерживаемые фильтры:

```js
{
  category: "books",   // "all" отключает фильтр категории
  inStockOnly: true,   // false отключает фильтр наличия
  maxPrice: 2500       // null отключает ограничение цены
}
```

Все условия применяются одновременно.

### 3. Поиск по тексту

```js
searchProducts(products, query)
```

Требования:

- игнорировать регистр и пробелы по краям;
- искать в `title` и элементах массива `tags`;
- пустой запрос возвращает копию исходного массива.

### 4. Сортировка

```js
sortProducts(products, sort)
```

Поддержать варианты:

- `price-asc`;
- `price-desc`;
- `rating-desc`;
- `title-asc`;
- `default` или неизвестное значение — исходный порядок.

Исходный массив изменять нельзя. Можно использовать `toSorted()` или сначала создать копию массива.

### 5. Статистика

```js
getCatalogSummary(products)
```

Вернуть:

```js
{
  count: 3,
  inStockCount: 2,
  totalPrice: 5500,
  averageRating: 4.7
}
```

Средний рейтинг округлите до одного знака. Для пустого массива он равен `0`.

### 6. Общий сценарий

```js
selectProducts(products, options)
```

Функция последовательно применяет:

```text
фильтрацию → поиск → сортировку
```

`options` содержит фильтры, `query` и `sort`.

## Запуск

```bash
npm test
npm start
```

## Самопроверка

- `findProductById()` возвращает один объект, а не массив;
- `filter()` используется для выбора элементов, `find()` — для одного элемента;
- поиск работает по названию и тегам;
- пустой запрос не возвращает исходную ссылку на массив;
- сортировка не изменяет `products`;
- comparator возвращает отрицательное число, ноль или положительное число, а не `true/false`;
- статистика вычисляется из переданного массива;
- `selectProducts()` переиспользует остальные функции.
